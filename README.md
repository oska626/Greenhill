# 青山城文字冒險

## 核心玩法：整句意圖，逐事結算

玩家可以用一句話講一連串做法。理解服務會分辨連續任務與同一招中的配合動作；沒有服務時，明確的「先甲，再乙」仍可辨認。系統逐事檢查人物、物件、距離與持有狀態，用更新後的場景狀態結算下一項。NPC 或敵人可在任何一步介入；局勢轉變時，餘下打算不會偷偷完成。

黑泥街試點：玩家可說「先替陸千帆敷藥，再向張斷骨談規費」。敷藥結算後，才會檢查是否仍有機會交涉；若刀手插入，旁白須交代哪些已嘗試、哪些尚未做。系統不保證整句每項都成功。

多步自由行動現已接入所有階段的 `F. [自由行動]` 入口；黑泥街提供較完整的場景結算。即時危險的場景會在敘事末尾顯示具體提示。其他地標、第一章與既有預設選項的時間及資源結算仍沿用原有回合規則，尚未統一改造。

玩家提出的推測、承諾與自稱權限不會自動成為世界事實。隱藏線索須在場景狀態或規則中預先確定，查證後才會揭露。危險以場景行為提示，文末用斜體括號顯示眼前可觀察的變化，不向玩家宣告剩餘回合。NPC 可以拒絕、考慮或有限度配合，並記住玩家說過的承諾；說過不等於履行。全城承諾履約狀態仍待結構化處理。

## 啟用 AI 自由行動理解

遊戲伺服器已有 Azure OpenAI 行動理解器。玩家用 `F. [自訂手段]` 輸入行動時，模型只解析意圖、目標和在場物件；成敗、資源與後果由遊戲規則結算。

1. 本機開發時，可將 `.env.example` 複製為 `.env.local`，填入 Azure OpenAI 資源的 endpoint、API key 和 Chat Completions deployment 名稱。不要把真實 API key 提交到 Git。
2. 執行 `npm install` 和 `npm run dev`。
3. Vercel 部署會直接讀取專案環境變數。確認 Vercel 已設定 `AZURE_OPENAI_ENDPOINT`、`AZURE_OPENAI_API_KEY`、`AZURE_OPENAI_DEPLOYMENT_NAME`，並套用到目標環境。環境變數有變更時，重新部署後才會套用。

環境變數只在伺服器讀取，瀏覽器不會接收 API key。若服務未設定或請求失敗，遊戲會使用有限的後備理解器；後備理解器無法辨認的自由行動會提示服務暫不可用。

執行 `npm run typecheck` 和 `npm test` 可檢查程式與遊戲規則。要驗證模型理解效果，需在已設定 endpoint 的環境中實際輸入自由行動。
