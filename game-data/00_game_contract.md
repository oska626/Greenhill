# 青山城：遊戲設計契約

本文件是目前可遊玩版本的準則。其他 `game-data` 文件只作人物與歷史背景參考；若與本文件衝突，以本文件為準。

## 世界與敘事

- 玩家只可身處七個城西據點：青鋒堂總壇、晚秋茶寮、黑泥街、鬼骰坊、裂石擂、苦煙館、夜雨樓。
- 玄武樓、官府、外城等只會對城西造成壓力，不可成為移動目的地。
- 只寫古代底層市井江湖；沒有神怪、修仙、高武或現代科技。
- 旁白以第二人稱「你」推進。玩家名號只在 NPC 對白中出現。所有旁白、對白與故事交代一律用自然繁體中文書面語，不用廣東話或現代口語。
- 故事文字要有起伏：從具體動作或器物切入，讓事件推進，再顯出人物的打算與代價，最後落在眼前的抉擇或未解的壓力。長短句交錯，語意連貫；不寫成條列式報告，不堆典故、口號或華麗形容詞。
- 一般回合敘事為 90–220 字，嚴格兩段，以 `\n\n` 分隔；NPC 對白在第二段另起一行。創角開場採用固定的何不歸對白，先評斷人物，再交代玄武樓、金冊莊與城西的危局，最後說明差事。原地行動不重複描寫環境。
- NPC 對白以 `lib/npc-voices.ts` 的人物聲線為準：性格由關注的事、用字和句長呈現；每句都應像角色在當下會說的話。固定對白與人物當回合確定事件須一致。

## 數值與因果

- 第一回合依名號、出身、特質由 TypeScript 裁定氣血與內力上限，總點數 140–170；往後不由 AI 改寫。
- 自訂創角分別輸入性別、技能、性格；技能作為初始特質計算屬性，三項資料寫入存檔。第一回合何不歸依技能與性格作具體評斷，性別可影響自然稱呼，但不可推斷能力；對白不逐項複述資料。AI 不可用時，後備對白也須像角色說話。
- `silver` 是私銀，`factionFunds` 是公款，兩者不可混用。每筆變動須在敘事明說，後端只接受有限數值。
- 自訂合理市井手段按特質裁決；超現實行為判作幻覺或出醜，扣氣血。
- 重大行為記入 `worldFlags`，後續 NPC 反應及事件要受其影響。
- `hozaiDefense` 範圍為 0–100，玄武樓持續施壓，修補防線須付公款。

## 回合結構

1. 青鋒堂領命：拿草藥，受命救陸千帆及收五十文規費。
2. 晚秋茶寮：以草藥換金創散，得知伏擊警訊。
3. 黑泥街：給陸千帆敷藥，向張斷骨收規費，呼哨引爆伏擊。
4. 市集伏擊：與陸千帆突圍，解鎖沙盒。
5. 城西沙盒：七據點路由、黑拳賺私銀、買藥回血、市集收公款、以公款固防；玄武樓施壓。第 8 回合起每隔至少五回合觸發城西事件，依次為市集插旗、規費帳失頁、可疑傷藥。事件選項處理後留下資源及因果結果，再回到七據點沙盒。舊存檔若已過第 8 回合，下一次行動可觸發首個事件。

前四幕每個 A–E 選項都結合態度與實際行動，並順序推進一幕。敵人未現身，不可先出現迎戰選項；同伴必須在場才可協助。

## 技術邊界

`lib/game-engine.ts` 負責階段、移動、道具、收支、氣血、內力、因果和當前事件選項。`app/api/turn/route.ts` 只請 AI 用確定事件寫敘事，並帶入上一回合敘事以減少重複；AI 回傳的數值、道具及選項均不生效。AI 不可用時，後端產生同規格的敘事，遊戲仍可繼續。
