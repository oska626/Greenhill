# 03 — 主線進度、重大事件與結局判定

## 1. 遊戲推進階段 (Phase 1–3)

### Phase 1：街頭立足與插旗暗戰（地盤與生存）
* **階段目標**：玩家作為明心閣底層雜役站穩陣腳，摸清同門底細，掌握基礎市井泥漿武學；保住城西現存三大核心偏門產業（市集例錢、聚財坊賭檔、怡紅院）的日常銀兩收益[span_17](start_span)[span_17](end_span)[span_18](start_span)[span_18](end_span)。
* **主要衝突**：
  * 匯智樓精銳打手越界踩線，試圖強插暗旗，吞併城東城西交界的泥濘市集與小賭坊[span_19](start_span)[span_19](end_span)[span_20](start_span)[span_20](end_span)。
  * 明心閣現金流吃緊，何仔四處打太極賒賬，阿黃與衛林帶頭在爛泥窄巷中與外來刀手血腥火併[span_21](start_span)[span_21](end_span)[span_22](start_span)[span_22](end_span)。
* **晉級條件**：成功化解匯智樓首波插旗吞併，或在一次市集械鬥中立威，引來青山城各方勢力正式注目[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span)。

---

### Phase 2：豪紳逼遷與邪毒擴散（內部危機與陰謀）
* **階段目標**：應對城南青山資產管理的經濟封殺逼遷，以及匯智樓走私的「邪派試藥藥人」流入城西街頭引發的恐慌[span_25](start_span)[span_25](end_span)[span_26](start_span)[span_26](end_span)。
* **主要衝突**：
  * 黃棠以城主府官印地契與租稅漏洞，勒令查封明心閣名下的怡紅院、聚財坊與仙館[span_27](start_span)[span_27](end_span)[span_28](start_span)[span_28](end_span)。
  * 匯智樓秘密煉製丹藥的發狂「藥人」逃竄至城西市集大開殺戒，城北朝廷官衙（僧臣）藉機派遣大內密探暗中封鎖調查[span_29](start_span)[span_29](end_span)[span_30](start_span)[span_30](end_span)。
  * 明心閣內部出現裂痕：何仔防線瀕臨極限、阿黃私自伏擊險死、衛林拳傷舊患復發、域卡度黑市走私被官府與仇家盯梢[span_31](start_span)[span_31](end_span)[span_32](start_span)[span_32](end_span)。
* **晉級條件**：查明藥人案背後的邪派丹方黑幕，或粉碎一次重大收契奪產陰謀，並在城北「僧臣」或城南「黃棠」之間建立初步斡旋渠道[span_33](start_span)[span_33](end_span)[span_34](start_span)[span_34](end_span)。

### Phase 3：青山全城火併與清洗（終局對決）
* **階段目標**：三大勢力矛盾徹底激化，城主西涼準備借刀殺人清洗江湖幫派，朝廷僧臣正式亮出底牌發動鐵腕清場[span_35](start_span)[span_35](end_span)[span_36](start_span)[span_36](end_span)。
* **主要衝突**：
  * 匯智樓傾巢而出全面強攻城西七大地標，發動滅門級街頭大火併[span_37](start_span)[span_37](end_span)[span_38](start_span)[span_38](end_span)。
  * 城南黃金碉樓佈設機關重弩與鐵甲死士封鎖全城要道，西涼城主親衛坐收漁人之利[span_39](start_span)[span_39](end_span)[span_40](start_span)[span_40](end_span)。
  * 玩家武功成形，必須在同門生死、利益背叛與全城清洗之間做出最終抉擇[span_41](start_span)[span_41](end_span)。

## 2. 核心事件節點 (Major Event Flags)

### 【事件 1：市集插旗血戰】（觸發：初期交界街區爭奪）
* **情境**：匯智樓管事帶領十數名持刀傭兵，硬踩城西「泥濘市集」，毆打攤販並強立堂口收保護費，限明心閣日落前交出市集街道契紙[span_42](start_span)[span_42](end_span)[span_43](start_span)[span_43](end_span)。
* **分支與代價**：
  * **硬碰開片（派阿黃 / 衛林 / 玩家拔刀）**：保住街道規費，但同門負傷，引來鋒少記恨並升級刺殺威脅[span_44](start_span)[span_44](end_span)。
  * **暗盤使詐（派奇仕 / 域卡度 / 玩家玩泥漿陰招）**：動用生石灰、假銀票或引誘瘋狗街鼠打亂對手陣腳，逼退傭兵，但市集商戶暫停營業一日[span_45](start_span)[span_45](end_span)[span_46](start_span)[span_46](end_span)。
  * **割地息事（交由何仔委曲求全）**：何仔跪低認契弟讓出半條街，明心閣收入銳減，何仔防線數值受損[span_47](start_span)[span_47](end_span)[span_48](start_span)[span_48](end_span)。

### 【事件 3：城南天價贖契令】（觸發：中期生存危機）
* **情境**：黃棠派重甲死士送達城主府蓋印之官牒，聲稱明心閣古堂地契早已失效，定性為非法強佔官地，限期繳交五百兩紋銀補契，否則即日移平總壇[span_58](start_span)[span_58](end_span)[span_59](start_span)[span_59](end_span)。
