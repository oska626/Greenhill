# 03 — 主線進度、重大事件與結局判定

> 此文保留遠期擴展情節構想。現行版本已有四幕教學、七據點差事及城東吞併危機；實際規則以 [00_game_contract.md](00_game_contract.md) 為準。文中跨城行動不是玩家選項。

## 1. 遊戲推進階段 (Phase 1–3)

### Phase 1：街頭立足與插旗暗戰（地盤與生存）
* **階段目標**：玩家作為青鋒堂底層雜役站穩陣腳，摸清同門底細，掌握基礎市井泥漿武學；保住城西現存三大核心偏門產業（市集例錢、鬼骰坊賭檔、夜雨樓）的日常銀兩收益[span_17](start_span)[span_17](end_span)[span_18](start_span)[span_18](end_span)。
* **主要衝突**：
  * 玄武樓精銳打手越界踩線，試圖強插暗旗，吞併城東城西交界的黑泥街與小賭坊[span_19](start_span)[span_19](end_span)[span_20](start_span)[span_20](end_span)。
  * 青鋒堂現金流吃緊，何不歸四處打太極賒賬，霍破陣與衛沉岳帶頭在爛泥窄巷中與外來刀手血腥火併[span_21](start_span)[span_21](end_span)[span_22](start_span)[span_22](end_span)。
* **晉級條件**：成功化解玄武樓首波插旗吞併，或在一次市集械鬥中立威，引來青山城各方勢力正式注目[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span)。

---

### Phase 2：豪紳逼遷與邪毒擴散（內部危機與陰謀）
* **階段目標**：應對城南金冊莊的經濟封殺逼遷，以及玄武樓走私的「邪派試藥藥人」流入城西街頭引發的恐慌[span_25](start_span)[span_25](end_span)[span_26](start_span)[span_26](end_span)。
* **主要衝突**：
  * 黃萬鈞以城主府官印地契與租稅漏洞，勒令查封青鋒堂名下的夜雨樓、鬼骰坊與苦煙館[span_27](start_span)[span_27](end_span)[span_28](start_span)[span_28](end_span)。
  * 玄武樓秘密煉製丹藥的發狂「藥人」逃竄至城西市集大開殺戒，城北朝廷官衙（玄渡）藉機派遣大內密探暗中封鎖調查[span_29](start_span)[span_29](end_span)[span_30](start_span)[span_30](end_span)。
  * 青鋒堂內部出現裂痕：青鋒堂命脈瀕臨極限、霍破陣私自伏擊險死、衛沉岳拳傷舊患復發、陸千帆黑市走私被官府與仇家盯梢[span_31](start_span)[span_31](end_span)[span_32](start_span)[span_32](end_span)。
* **晉級條件**：查明藥人案背後的邪派丹方黑幕，或粉碎一次重大收契奪產陰謀，並在城北「玄渡」或城南「黃萬鈞」之間建立初步斡旋渠道[span_33](start_span)[span_33](end_span)[span_34](start_span)[span_34](end_span)。

### Phase 3：青山全城火併與清洗（終局對決）
* **階段目標**：三大勢力矛盾徹底激化，城主燕鎮嶽準備借刀殺人清洗江湖幫派，朝廷玄渡正式亮出底牌發動鐵腕清場[span_35](start_span)[span_35](end_span)[span_36](start_span)[span_36](end_span)。
* **主要衝突**：
  * 玄武樓傾巢而出全面強攻城西七大地標，發動滅門級街頭大火併[span_37](start_span)[span_37](end_span)[span_38](start_span)[span_38](end_span)。
  * 城南黃金碉樓佈設機關重弩與鐵甲死士封鎖全城要道，燕鎮嶽城主親衛坐收漁人之利[span_39](start_span)[span_39](end_span)[span_40](start_span)[span_40](end_span)。
  * 玩家武功成形，必須在同門生死、利益背叛與全城清洗之間做出最終抉擇[span_41](start_span)[span_41](end_span)。

## 2. 核心事件節點 (Major Event Flags)

### 【事件 1：市集插旗血戰】（觸發：初期交界街區爭奪）
* **情境**：玄武樓管事帶領十數名持刀傭兵，硬踩城西「黑泥街」，毆打攤販並強立堂口收保護費，限青鋒堂日落前交出市集街道契紙[span_42](start_span)[span_42](end_span)[span_43](start_span)[span_43](end_span)。
* **分支與代價**：
  * **正面迎戰（派霍破陣 / 衛沉岳 / 玩家拔刀）**：保住街道規費，但同門負傷，引來裴無鋒記恨並升級刺殺威脅[span_44](start_span)[span_44](end_span)。
  * **暗盤使詐（派祁觀衡 / 陸千帆 / 玩家玩泥漿陰招）**：動用生石灰、假銀票或引誘瘋狗街鼠打亂對手陣腳，逼退傭兵，但市集商戶暫停營業一日[span_45](start_span)[span_45](end_span)[span_46](start_span)[span_46](end_span)。
  * **割地息事（交由何不歸委曲求全）**：何不歸跪低認契弟讓出半條街，青鋒堂收入銳減，青鋒堂命脈數值受損[span_47](start_span)[span_47](end_span)[span_48](start_span)[span_48](end_span)。

---

### 【事件 2：試藥藥人與黑市密函】（觸發：陸千帆截獲私貨）
* **情境**：陸千帆在江邊暗渠走私時，誤截玄武樓一批運往城外的「發狂試藥藥人」與邪派毒丹圖譜[span_49](start_span)[span_49](end_span)[span_50](start_span)[span_50](end_span)[span_51](start_span)[span_51](end_span)。
* **分支與代價**：
  * **留扣自用**：交由【苦煙館】顧忘生調製禁藥、【夜雨樓】柳照霜解構經脈弱點，解鎖獨門毒攻或偏門殺招，但引來玄武樓死士瘋狂追殺[span_52](start_span)[span_52](end_span)[span_53](start_span)[span_53](end_span)。
  * **密報朝廷**：暗中將密函送交【城北】玄渡，換取官府暫緩取締城西產業，但極易被燕鎮嶽城主府視為反骨內奸[span_54](start_span)[span_54](end_span)[span_55](start_span)[span_55](end_span)。
  * **敲詐勒索**：由【鬼骰坊】祁觀衡出面談判，向裴無鋒勒索巨額贖金暫解門派財困，但在城西街坊間名聲掃地[span_56](start_span)[span_56](end_span)[span_57](start_span)[span_57](end_span)。

### 【事件 3：城南天價贖契令】（觸發：中期生存危機）
* **情境**：黃萬鈞派重甲死士送達城主府蓋印之官牒，聲稱青鋒堂古堂地契早已失效，定性為非法強佔官地，限期繳交五百兩紋銀補契，否則即日移平總壇[span_58](start_span)[span_58](end_span)[span_59](start_span)[span_59](end_span)。
* **分支與代價**：
  * **暴力抗命**：衛沉岳與霍破陣率眾死守大門，與城南機關守衛正面搏殺，面臨重型守城弩箭雨威脅[span_60](start_span)[span_60](end_span)[span_61](start_span)[span_61](end_span)。
  * **尋找文牒破綻**：依賴祁觀衡核算暗帳之才，配合【晚秋茶寮】收集的官紳偷漏稅八卦，找出黃萬鈞私吞城府公款的把柄反制[span_62](start_span)[span_62](end_span)[span_63](start_span)[span_63](end_span)。
  * **潛入夜襲**：夜潛城南黃金碉樓外圍破壞機關庫，脅迫黃萬鈞親自撤回官牒[span_64](start_span)[span_64](end_span)[span_65](start_span)[span_65](end_span)[span_66](start_span)[span_66](end_span)。

---

### 【事件 4：青鋒堂命脈歸零】（現行觸發：命脈歸零或第 70 回合）
* **情境**：玄武樓同時向城西七處據點插旗，何不歸召集殘部，玩家須決定最後去路。
* **分支與代價**：固守城西須靠先前完成的據點差事及剩餘命脈；割地可保住殘存同門，卻失去自主；獨自撤走則保住玩家性命，青鋒堂瓦解。

---

### 【事件 5：玄渡的誅殺密令】（觸發：朝廷收網前夕）
* **情境**：城北玄渡密會玩家，出示朝廷平亂金牌，敕令玩家暗殺燕鎮嶽城主或裴無鋒，承諾事成後扶植青鋒堂合法掌管全城地下秩序[span_73](start_span)[span_73](end_span)[span_74](start_span)[span_74](end_span)。
* **分支與代價**：
  * **充當朝廷鷹犬**：執行暗殺，獲取官府庇護文牒與高階大內內功，但隨時面臨事成被滅口之險[span_75](start_span)[span_75](end_span)[span_76](start_span)[span_76](end_span)。
  * **反手倒戈**：將玄渡密函轉售燕鎮嶽或裴無鋒，換取巨額賞金與江湖霸主盟約[span_77](start_span)[span_77](end_span)。
  * **趁火打劫**：暗中引爆三方大混戰，趁亂洗劫各大總舵藏寶閣與鎮派神兵[span_78](start_span)[span_78](end_span)。

## 4. 多結局判定矩陣 (Endings)

### 結局 A【城西夜天子】（完美破局）
* **達成條件**：保住城西 5 處以上地標產業、格殺或重挫裴無鋒、化解黃萬鈞逼遷、同門存活三人以上[span_95](start_span)[span_95](end_span)。
* **終局**：青鋒堂徹底肅清城西並反噬部分城東商道，玄武樓殘部作鳥獸散[span_96](start_span)[span_96](end_span)[span_97](start_span)[span_97](end_span)。玩家以市井泥漿流稱霸一方，成為青山城不可撼動的地下話事人[span_98](start_span)[span_98](end_span)[span_99](start_span)[span_99](end_span)。

### 結局 B【招牌落地·血洗瓦舍】（敗亡覆滅）

* **終局**：何不歸橫死，衛沉岳戰至力竭，青鋒堂青瓦招牌被當街劈碎踩爛[span_102](start_span)[span_102](end_span)[span_103](start_span)[span_103](end_span)。殘存同門淪為玄武樓試藥藥人或四散逃亡之流寇[span_104](start_span)[span_104](end_span)[span_105](start_span)[span_105](end_span)。
