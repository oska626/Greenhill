# 01 — 青山城世界觀與底層生態

## 1. 地理、人口與勢力版圖

### 人口階梯分布
* **城西（平民核心，人口最多）**：全城絕大部分底層勞動人口聚集地[span_0](start_span)[span_0](end_span)。因物價水平最低、租金便宜，混雜大量小販、流民、苦力雜工與落魄幫派[span_1](start_span)[span_1](end_span)。昔日神鋒鑄劍重地如今荒廢破敗，古舊瓦舍與殘破木樓林立，泥濘窄巷污水橫流。
* **城東（商貿富裕，人口約為城西的 50%）**：富裕階層與武裝勢力駐紮區[span_2](start_span)[span_2](end_span)。生活成本高昂，居住門檻高，人口密度僅有城西一半[span_3](start_span)[span_3](end_span)。
* **城南（官紳特區，人口最少）**：巨富商賈、城府官紳與外來權貴聚居地[span_4](start_span)[span_4](end_span)。高門朱戶、深宅大院，由城主府在背後全力撐腰，平民無通行文牒不得踏入[span_5](start_span)[span_5](end_span)。
* **城北（官府禁區，人口極度稀少且流動成謎）**：朝廷正規衙門與官僚盤踞之地，非江湖幫派勢力，氣氛肅殺封閉，平民與幫派無故不敢靠近[span_6](start_span)[span_6](end_span)。

### 五大勢力與地盤架構

#### 【城西】何仔勢力範圍（明心閣）
* **勢力淵源**：前身以「鍛造神鋒」名震江湖，門派沒落後技術斷代、名劍蒙塵，現已淪落為依靠販夫走卒、經營下九流偏門（私娼、賭檔、高利貸、煙館、黑市拳賽、強收例錢）苟延殘喘的市井流氓團伙。
* **環境氛圍**：破舊瓦舍與舊木樓錯落，巷弄陰暗潮濕，泥濘路面污水漫流；街頭巷尾十二時辰皆有地痞流氓聚眾打躉看場，維持底層脆弱秩序[span_7](start_span)[span_7](end_span)。
* **核心據點與城西地標體系**：
  1. **明心閣（勢力大本營）**：
     * **風貌與定位**：殘存的青瓦石砌古堂，正廳後的古劍爐早已熄滅冷卻，現為幫派總壇與同門避風港。
     * **功能**：存檔、全額休整（回滿氣血與內力）、門派資源分配。
     * **駐守 NPC**：**何仔**（日常駐守於議事堂，商討應對城主府及外敵對策，派發城西主線與生存委託）。
  2. **怡紅院（平民妓院）**：
     * **風貌與定位**：懸掛褪色紅燈籠的雙層舊木樓，脂粉香氣混雜劣質酒氣，為明心閣傳統邊緣產業。
     * **功能**：情報收集（打探三教九流與城主府動向）、特殊交際（聽曲或留宿補充內力）、傳授武學。
     * **駐守 NPC**：**玉樺**（日常駐守應對各路恩客，提供「教訓走數嫖客」、「排查外派耳目」等委託，可向其修習身法與陰柔暗器）。
  3. **聚財坊（地下賭檔 / 高利貸錢莊）**：
     * **風貌與定位**：戒備森嚴的深院大屋，內裡骰子叫喝震天、烏煙瘴氣，為明心閣核心現金流來源。
     * **功能**：小額博彩（押大小/骰寶）、緊急借貸（九出十三歸高利貸）、傳授武學。
     * **駐守 NPC**：**奇仕**（掌管暗帳與骰局，派發「捉拿老千」、「向惡霸老賴收數」等任務，可向其修習指法與破綻辨識）。
  4. **仙館（黑市煙檔 / 毒窟）**：
     * **風貌與定位**：門口垂掛厚重黑布簾的偏僻深巷瓦舍，常年瀰漫甜膩致幻藥氣，底層道友與落魄客聚集之地。
     * **功能**：黑市禁藥與特殊毒物交易、底層黑市消息集散。
     * **駐守 NPC**：**佚名**（神經質的配藥人，派發「避開官差護送禁藥私貨」、「料理發狂道友」等高風險委託）。
  5. **武館（黑市拳館）**：
     * **風貌與定位**：粗木樁與黃泥地圍起的地下死鬥擂台，圍欄滿佈乾涸血跡，亡命武者爭名奪利之地。
     * **功能**：參與黑市打擂（賺取賞金與江湖聲望）、市井打鬥事件觸發、傳授武學。
     * **駐守 NPC**：**衛林** / **阿黃**（拳館台柱與打手教頭，派發「地下擂台爭霸」、「抵禦外派踢館」任務，可向其修習外門剛猛拳腳與硬氣功）。
  6. **市集（主街露天集市）**：
     * **風貌與定位**：泥濘破爛的主街木棚集市，苦力、流民、走卒雜處，市井暗流湧動。
     * **功能**：觸發街坊日常對話、探聽江湖傳聞、排查匯智樓插旗眼線。
     * **駐守 NPC**：**域卡度**（帶領幫眾巡街壓場，派發「向各攤販強制徵收例錢（陀地）」、「彈壓拒繳刺頭」等任務）。
  7. **容姐茶檔（街角攤檔）**：
     * **風貌與定位**：巷口搭建的簡陋粗竹油布棚，幾條長板凳配一個老舊大茶煲。
     * **功能**：基礎物資補給（粗茶、草藥、乾糧，提供低階氣血/體力恢復）、打聽市井坊間八卦。
     * **駐守 NPC**：**容姐**（熱心街坊長輩，提供平價雜貨買賣與草藥採集小委託）。

#### 【城東】鋒少勢力範圍（匯智樓）
* **環境氛圍**：庭院深廣、白牆黑瓦、修整潔淨；全天候有全副武裝打手及精銳私兵分班巡邏[span_8](start_span)[span_8](end_span)。
* **核心據點**：總部設於「匯智樓」[span_9](start_span)[span_9](end_span)。
* **經營業務**：私人傭兵雇傭所、黑市兵器甲冑交易所、人口販賣、秘密活人試藥與邪派丹藥研製[span_10](start_span)[span_10](end_span)。資產雄厚，財雄勢大[span_11](start_span)[span_11](end_span)。

#### 【城南】黃棠勢力範圍（青山資產管理）
* **環境氛圍**：高門重院、雕樑畫棟的高層連綿碉樓，四時明燈高懸；配置西域精巧機關重弩與重金豢養的頂級護衛，秩序森嚴。
* **核心據點**：總部設於「青山資產管理」名下之黃金產業中心[span_12](start_span)[span_12](end_span)。
* **經營業務**：壟斷全城田宅買賣、兼併土地、掌控各大商行契紙；為城主西涼暗中洗劫不義之財與洗黑錢的「白手套」，資產極度龐大[span_13](start_span)[span_13](end_span)。

#### 【城北】朝廷官府特派勢力（非幫派）
* **勢力性質**：官方朝廷駐軍與特務機關，獨立於青山城本土幫派體系之外[span_14](start_span)[span_14](end_span)。
* **表面關係**：名義上聽命於城主西涼，維持公堂運作與名義法令[span_15](start_span)[span_15](end_span)。
* **暗中底牌**：內部人員絕大多數由朝廷中央直接委派，真正職責是釘在青山城的一根刺，全天候暗中監視西涼城主府及三大黑道勢力的一舉一動[span_16](start_span)[span_16](end_span)。
* **管理者**：**「僧臣」**（身份詭秘、深居簡出，兼具僧侶與朝廷重臣雙重做派）[span_17](start_span)[span_17](end_span)。
* **核心據點**：**不詳**（極度隱蔽，對外僅有一座空洞肅穆的官衙，真正發號施令之核心指揮所全城無人知曉）[span_18](start_span)[span_18](end_span)。

#### 【城中】西涼城主府
* **統治現狀**：青山城名義上的最高統治者，掌控正規駐軍與公權力，城東、城西、城南三大勢力皆需聽其差遣並納貢[span_19](start_span)[span_19](end_span)。
* **暗流危機**：西涼行事雖然一手遮天、黑白通吃，但對城北「僧臣」與朝廷耳目極為忌憚，行事處處防範被城北抓到謀反或越軌把柄[span_20](start_span)[span_20](end_span)。

## 2. 底層經濟、保護費機制與地盤衝突

### 貨幣體系
* 1 兩銀 = 1,000 文（銅錢）[span_21](start_span)[span_21](end_span)。

### 生活成本與物價參考
* **粗茶 / 粗糧飯一碗**：5 文（勉強飽肚，無肉食油水）[span_22](start_span)[span_22](end_span)。
* **劣質生鏽鐵刀一把**：40 文（地攤黑鐵貨，劈砍數次極易崩口）[span_23](start_span)[span_23](end_span)。
* **底層雜役 / 打手日薪**：約 10–25 文[span_24](start_span)[span_24](end_span)。
* **各區街頭檔口 / 瓦舍商舖月度保護費**：城西街邊小檔約 50–150 文；臨街商舖約 300–500 文[span_25](start_span)[span_25](end_span)。城東同類商戶規費高出兩至三倍[span_26](start_span)[span_26](end_span)。

### 保護費機制與街頭械鬥（核心衝突推演）
* **民生保護費本質**：
  * 保護費完全由各勢力向「自身轄區」內的街坊、攤販、賭檔、暗娼及店舖強行徵收，是維持幫派日常營運與養打手的核心現金流[span_27](start_span)[span_27](end_span)。
  * 明心閣與匯智樓互不納貢，不存在上下級進貢關係，雙方純粹是勢成水火的地盤爭奪死敵[span_28](start_span)[span_28](end_span)。
* **集體毆鬥與地盤吞併**：
  * **日常械鬥**：城東與城西交界處經常爆發數十至上百人的幫派集體械鬥（爛仔開片）[span_29](start_span)[span_29](end_span)。爭奪核心不是江湖義氣，而是**「爭奪該街道的插旗收規權」**[span_30](start_span)[span_30](end_span)。
  * **經濟連鎖**：匯智樓每奪下一條城西街道，該街道所有商戶的民生保護費即刻轉入匯智樓口袋；明心閣失去地盤便意味著收入縮減，養不起手下爛仔，進而引發滅門崩潰[span_31](start_span)[span_31](end_span)。
  * **力量差距**：匯智樓倚仗精良兵器、傭兵陣型強行推移地盤邊界；明心閣則靠熟悉街頭巷戰、地痞泥漿打法與陰招死守防線[span_32](start_span)[span_32](end_span)。
* **禁戰區域規則**：
  * **城南禁區**：受城主府親衛與機關重弩護衛，設有嚴格暴力限制[span_33](start_span)[span_33](end_span)。嚴禁當街械鬥見血，違者就地格殺並開出天價罰單；衝突全轉為暗盤收購與經濟封殺[span_34](start_span)[span_34](end_span)。
  * **城北禁區**：任何幫派分子踏入城北鬧事，均會被朝廷官差直接以「叛逆罪」秘密逮捕拘禁，自此下落不明[span_35](start_span)[span_35](end_span)。
* **存亡機制（死線設定）**：
  * 暫不設固定倒數死線[span_36](start_span)[span_36](end_span)。
  * 採用事件與累積數值驅動（核心地盤失守、保護費收入枯竭、重大械鬥慘敗等），由具體劇情事件推動門派危機[span_37](start_span)[span_37](end_span)。

## 3. 市井武學體系

### 階級差異與打法風格

#### 正規武學（名門正派 / 匯智樓精銳 / 朝廷密探）
* **風格淵源**：傳統正統武學體系[span_38](start_span)[span_38](end_span)。
* **戰鬥特性**：講究內功經脈吐納、名家套路與合擊陣法；依賴充足肉食調養與名貴兵刃，正面硬碰具備絕對壓制力與長久氣脈[span_39](start_span)[span_39](end_span)。

#### 市井泥漿流（明心閣雜役 / 街頭地痞流氓）
* **風格淵源**：街頭下九流搏擊、市井廝殺風格。
* **戰鬥特性**：毫無套路框架，專攻下三濫手段；就地取材（板凳、碎酒罈、生石灰撒眼、熱滾水潑面、生鏽鐵釘刺穴）；專打脆弱要害（踩腳趾、扯頭髮、撩陰、插眼、折手指），追求三秒內打殘對手或製造脫身機會[span_40](start_span)[span_40](end_span)。

### 修煉與同門傳授規則

* **盲練（摸索發力）**：無人指導、自行參悟[span_41](start_span)[span_41](end_span)。熟練度每次 +1% 至 +2%，伴隨氣血損耗或肉體反噬[span_42](start_span)[span_42](end_span)。
* **同門傳授（同伴指點）**：
  * **衛林 / 阿黃（武館）**：傳授外門硬功、摔跤擒拿與剛猛拳法。
  * **玉樺（怡紅院）**：傳授靈巧身法、暗器手法與柔勁卸力。
  * **奇仕（聚財坊）**：傳授辨穴指法、下三濫防身破綻擊打。
  * **何仔（明心閣）**：傳授泥鰍保命步法、街頭保命卸勁。
  * *規則*：熟練度每次 +5% 至 +10%，消耗同門好感度或需替其完成指定差事[span_43](start_span)[span_43](end_span)。
* **秘笈殘卷（黑市功法）**：黑市搜刮或巧取豪奪所得[span_44](start_span)[span_44](end_span)。熟練度大幅暴升，解鎖正統招式名稱，但極易引來外人覬覦與追殺[span_45](start_span)[span_45](end_span)。

## 4. 行囊負重與摸屍銷贓機制

### 行囊格數與擴充
- 基礎容量固定為 4 格，超過上限觸發「超載」（戰鬥命中與身法閃避大幅下修）[span_46](start_span)[span_46](end_span)。
- 擴充方式：購置容姐粗麻布袋（+2 格）、域卡度精工皮囊（+4 格）、或修煉負重吐納功法[span_47](start_span)[span_47](end_span)。

### 摸屍搜刮 (Looting)
- 戰鬥或暗殺結束後，玩家可選擇摸屍，獲取銅錢、兵刃、殘卷、或暗記證物[span_48](start_span)[span_48](end_span)。
- 搜刮消耗回合與時間，存在被巡邏護衛或官差撞破之風險[span_49](start_span)[span_49](end_span)。

### 黑市銷贓與人緣動態定價
- **容姐（茶檔/市井雜貨）**：價格視交情而定（30%–60%），專收各類普通生活雜物[span_50](start_span)[span_50](end_span)。
- **域卡度（市集）**：專收黑市機關、暗器、私鑄殘件，好感高時提供特製改裝[span_51](start_span)[span_51](end_span)。
- **奇仕（聚財坊）**：收繳高利貸欠條與爭議房契地契，轉化為堂口公款與門派聲望[span_52](start_span)[span_52](end_span)。
- **黑市當舖（死當）**：均一價 30% 賤賣，免除被仇家追查風險[span_53](start_span)[span_53](end_span)。
- **燙手貨（帶血印、門派徽記）**：正常商鋪拒收或強制扣減 50% 收購價[span_54](start_span)[span_54](end_span)。
