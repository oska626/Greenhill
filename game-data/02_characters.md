# 02 — 人物群像與動機設定

## 1. 城西·明心閣（底層殘部）

### 【何仔】閣主 / 老油條肉盾
- **駐守據點**：**城西 · 明心閣總壇（議事堂）**[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span)
- **身份定位**：明心閣名義話事人，整間閣的人肉盾牌，獨自周旋於各大黑道勢力與城主府之間[span_5](start_span)[span_5](end_span)。
- **表面偽裝**：死皮賴臉、嬉皮笑臉。極擅長打太極，習慣用極乾、極硬的爛笑話與自嘲化解殺氣，讓人誤以為他是個無能軟皮蛇[span_6](start_span)[span_6](end_span)。
- **底層動機**：誓死保住城西最後幾處基業與這班殘缺同門。寧願自己跪低認契弟吞屈辱，亦絕不讓手足淪為匯智樓試藥的藥人[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span)[span_9](start_span)[span_9](end_span)。
- **戰鬥風格**：市井泥鰍身法、受身卸力。正面攻擊力極弱，但極擅長捱打、閃避、跌跌撞撞中化解重擊[span_10](start_span)[span_10](end_span)。
- **【選項 4 交畀佢】反應邏輯**：必定主動上前嬉皮笑臉打圓場、自認下把位替玩家擋災，但會磨損其隱藏數值「何仔防線」[span_11](start_span)[span_11](end_span)。
- **對白範例**：
  > 「鋒少咁早起身，係咪你屋企屎渠爆咗呀，哈哈。」  
  > 「大家自己人，收埋啲㗎撐先唔好傷和氣。」

### 【奇仕】內務總管 / 毒舌帳房
- **駐守據點**：**城西 · 聚財坊（地下賭檔 / 錢莊）**[span_12](start_span)[span_12](end_span)[span_13](start_span)[span_13](end_span)
- **身份定位**：掌管明心閣賭檔暗帳、高利貸借據與情報彙整的算盤總管[span_14](start_span)[span_14](end_span)[span_15](start_span)[span_15](end_span)。
- **表面偽裝**：刻薄挑剔、算死草、寸嘴毒舌。開口必拆穿對方的假話與帳目破綻，笑騎騎放毒蛇[span_16](start_span)[span_16](end_span)。
- **底層動機**：城內最清醒的人。早已算透門派每個月的赤字與痛點，之所以未走，是因為深明城西一旦淪陷，覆巢之下無完卵[span_17](start_span)[span_17](end_span)。
- **派發委託 / 武學**：捉拿老千、向惡霸老賴追討高利貸；傳授辨穴指法與下三濫防身破綻擊打[span_18](start_span)[span_18](end_span)。
- **戰鬥風格**：短刃刺穴、下毒、撒石灰粉與生鏽鐵蒺藜。不出手則已，出手必打下三濫盲點[span_19](start_span)[span_19](end_span)。
- **【選項 4 交畀佢】反應邏輯**：當場用尖酸言詞揭穿對方痛腳或契紙漏洞，逼退敵人或轉移焦點，但極易將局勢推向火藥桶邊緣[span_20](start_span)[span_20](end_span)。
- **對白範例**：
  > 「你張借據連城主府官印都無，拎張廢紙上嚟收數，你當我聚財坊流㗎？」  
  > 「信佢一成，雙目失明。你仲企喺度做咩？收檔啦。」

### 【衛林】清場金牌 / 沉默打手

- **表面偽裝**：極度寡言戒備，整日於泥地擂台邊抱臂閉目或磨刀礪石。說話從不超過三句，多過三句必見血[span_24](start_span)[span_24](end_span)。
- **底層動機**：欠過明心閣前代長老的救命恩情，身負舊傷與仇恨，視守護門派後方陣地為唯一的生存理由[span_25](start_span)[span_25](end_span)。
- **派發委託 / 武學**：黑市擂台連勝爭霸、抵禦外派踢館；傳授外門剛猛拳腳與硬氣功[span_26](start_span)[span_26](end_span)。
- **戰鬥風格**：硬橋硬馬、重拳斷骨、碎石破風。擅長正面一打多開片，下手沉重狠辣[span_27](start_span)[span_27](end_span)。
- **【選項 4 交畀佢】反應邏輯**：完全不講廢話，直接以肉身或重拳強行破局。危機可瞬間壓制，但必引來官府或匯智樓更大規模的報復[span_28](start_span)[span_28](end_span)。
- **對白範例**：

### 【阿黃】前線瘋狗 / 爛頭卒
