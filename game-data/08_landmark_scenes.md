# 序章與第一章：八處地標現場規格

| 青鋒堂總壇 | 厚木正門、後門暗巷通城西貧民窟；正堂空曠。堂主在案前，兩名持刀堂眾守門，異常動作會受盤問。 | 案上燭台在堂主手邊，須逼近三步；兩側太師椅可踢翻，難擲；高牆儀式劍未開刃，須踩椅攀取。 |
| 晚秋茶寮 | 街角茶棚三面透風、背靠高牆，易逃難守；白日動手會招人圍觀。容晚秋守櫃檯。 | 土灶上沸水銅壺可取但燙手；缺腳木凳易碎；茶渣爛泥須俯身抓取，貼身會被搶攻。 |
| 黑泥街肉檔、巷口 | 肉檔在十字街角，後巷極窄且為死胡同；地面油滑，易被兩面包抄。 | 剁骨刀在張斷骨手中或肉案上，須先奪；木架懸肉鐵鉤須靠近；厚砧板須合力掀動；巷尾廢竹籮、餿水桶可阻路或墊腳攀牆。 |

## 地底暗網

- 晚秋茶寮：煮茶土灶底的空心石板。先得知入口，還要趁無人看守移開石板。
- 鬼骰坊：賬房後雜物堆下的鐵柵活門。須先進賬房、移重物，再以鑰匙或工具開門。此處是暗網樞紐，並非死路。
- 夜雨樓：後院酒窖深處廢棄巨桶內的暗門。須先避開護院進酒窖。

三個入口彼此相連。路線在兩端入口均已發現並打開後才顯示；已知位置不等於無視當前守衛、門鎖與距離。環境風險隨場面判斷，不能寫成永遠無法潛行、逃走或用火。
